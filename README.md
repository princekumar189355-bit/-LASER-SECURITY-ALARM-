# Laser Security Alarm

This is a simple electronics project using a laser module and an LDR sensor. When the laser beam is blocked, the buzzer and LED turn ON. When the laser beam reaches the LDR again, the alarm stops. I made this project to learn basic electronics and sensor working.

---

## Components Used

- Laser Module
- LDR (Light Dependent Resistor)
- Buzzer
- LED
- 220Ω Resistor
- Mini Breadboard
- Jumper Wires
- 9V Battery
- Battery Clip

---

## Features

- Detects interruption of laser beam
- LED and buzzer alert
- Simple breadboard circuit
- Battery powered
- Easy beginner project

---

## How It Works

1. Connect the 9V battery.
2. Point the laser beam at the LDR.
3. The LDR receives the laser light.
4. If someone blocks the laser beam, the buzzer and LED turn ON.
5. When the beam reaches the LDR again, the alarm turns OFF.
